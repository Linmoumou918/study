# Paper Summary Assistant

这是一个基于 Python 和 LLM API 编写的论文摘要分析工具。

用户可以输入一段论文摘要，程序会调用大模型 API，并从摘要中提取结构化信息，包括研究问题、方法、数据集、主要贡献和局限性。结果会以 JSON 格式保存到本地文件中。

本项目是 Python 学习中的第四个小项目，也是后续学习 RAG、论文阅读助手和文档问答系统的前置练习。

---

## 功能介绍

程序支持以下功能：

- 从命令行输入论文摘要
- 支持多行摘要输入
- 输入 `END` 结束摘要输入
- 调用 LLM API 分析摘要
- 使用 Prompt 模板控制模型输出
- 要求模型返回 JSON 格式结果
- 使用 `json.loads()` 解析模型输出
- 将结构化分析结果保存为 JSON 文件
- 如果模型返回内容不是合法 JSON，则保存原始回答

---

## 提取的信息

程序会从论文摘要中提取以下内容：

| 字段 | 含义 |
|---|---|
| `research_problem` | 研究问题 |
| `method` | 使用的方法 |
| `dataset` | 使用的数据集 |
| `contribution` | 主要贡献 |
| `limitation` | 局限性 |

如果摘要中没有明确提到某一项，模型应返回：

未明确提及
