# GitHub User Tool

这是一个用于查询 GitHub 用户信息的 Python 命令行工具

本项目是 Python API 调用练习，主要用于学习：

- Http 请求
- GitHub API
- JSON 数据分析
- 命令行参数 argparse
- 异常处理
- 文件保存

---


## 功能介绍

程序可以根据输入的 Github 用户名查询以下信息：

- 用户名
- GitHub 主页
- 粉丝数
- 公开仓库数
- 最近创建的 5 个仓库名称

同时支持将查询结果保存为 JSON 文件
